# C++ Piscine — From C to Object-Oriented Programming (OOP)

This repository tracks my first jump from **C** to **C++** and **Object-Oriented Programming (OOP)** as part of the C++ Piscine curriculum.

## What This Repo Is About
After working in C (pointers, manual memory management, structs, and procedural design), this repo focuses on building idiomatic C++ habits, mastering OOP principles, and working with the Standard Template Library (STL):
- **C to C++ transition:** `struct` vs. `class`, streams (`std::cout` / `std::cin`), references (`&`), and `const`-correctness
- **Object lifecycle & memory:** constructors, destructors, Orthodox Canonical Form (Coplien's form), and resource management
- **OOP pillars:** encapsulation, operator/function overloading, inheritance, and polymorphism
- **Templates, Exceptions & STL:** generic programming, exception handling, and standard containers—culminating in the final exercise implementing the **Ford-Johnson (merge-insertion) sorting algorithm**

## Structure
Each module and exercise lives in its own directory with its source files (`.hpp` / `.cpp`) and a `Makefile` (`-Wall -Wextra -Werror`).
